# ☕ Coffee Sales Dashboard Analysis

## 📊 Project Overview
This project presents an interactive Excel dashboard analyzing sales and transaction data for a coffee and food business.

## 🎯 Objectives
The dashboard answers key business questions such as:
- Total transactions, revenue, profit (KPIs)
- Sales distribution by product category
- Weekly and monthly sales trends
- Year-over-year revenue comparison
- Top-performing cities and categories
- Revenue vs profit analysis

## 📈 Key Features
- Dynamic dashboard with filters (Year, Month, City)
- KPI tracking (Revenue, Profit, Quantity, Transactions)
- Trend analysis (weekly & monthly)
- Category and city performance breakdown
- Comparative revenue vs profit visuals

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Dashboard Design

## 📌 Insights
- Identified top-performing cities and product categories
- Observed seasonal sales trends
- Highlighted profit vs revenue gaps
